# MacMouse 1.0.1

- Fixes MacMouse ignoring the mouse after a restart. When it launched at login before the mouse or its receiver had connected (for example behind a USB dock), it never found the mouse, so scrolling was not reversed and pointer speed was not applied until MacMouse was relaunched. It now picks up mice that connect at any time.

Requires macOS 14 or newer. The attached app supports Apple Silicon and Intel Macs.

## Install

```sh
brew upgrade --cask henrikhestnes/tap/macmouse
```

Or download `MacMouse.zip`, unzip it, and move **MacMouse.app** to **Applications**. Upgrades keep the Accessibility permission.

This build is signed with a self-signed certificate and has not been notarized by Apple. macOS may block the downloaded app through Gatekeeper. The cask does not disable or bypass Gatekeeper.
