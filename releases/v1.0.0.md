# MacMouse 1.0.0

Pointer speed, scroll wheel and mouse button settings for mice, from the menu bar. A port of LinearMouse that behaves like it for one scheme.

- Apply settings to one mouse (by default the Logitech USB Receiver) or all mice; trackpads are never touched.
- Set pointer speed and acceleration.
- Reverse scrolling and scroll a fixed number of lines per wheel tick.
- Zoom with ⌘ + scroll.
- Remap the middle, back, forward and sixth buttons to back, forward, middle click, Mission Control, App Exposé or Show Desktop.

Requires macOS 14 or newer. The attached app supports Apple Silicon and Intel Macs.

## Install

```sh
brew install --cask henrikhestnes/tap/macmouse
```

Or download `MacMouse.zip`, unzip it, and move **MacMouse.app** to **Applications**.

On first launch, enable MacMouse in **System Settings → Privacy & Security → Accessibility**.

This build is signed with a self-signed certificate and has not been notarized by Apple. macOS may block the downloaded app through Gatekeeper. The cask does not disable or bypass Gatekeeper.
